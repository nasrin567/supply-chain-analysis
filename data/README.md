
# 📊 Dataset

This project uses the DataCo Supply Chain Dataset for supply chain delivery,
profitability, bottleneck, and delay-risk analysis.

The original dataset is not included in this repository because of GitHub's
file-size limitation.

## 📁 Required Dataset Files

The notebook uses:

- `DataCoSupplyChainDataset.csv`
- `DescriptionDataCoSupplyChain.csv`

## 🔗 Dataset Source

DataCo Smart Supply Chain Dataset:

https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

Download the dataset and place the CSV files in the `data/` folder before
running the notebook.
